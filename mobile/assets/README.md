# Mobile assets

Drop the following here before building:

- `icon.png` — 1024×1024, no transparency
- `splash.png` — 1242×2436 (or larger; Expo will scale)
- `adaptive-icon.png` — 1024×1024, Android
- `favicon.png` — 48×48, web target

`expo prebuild` and `eas build` will read these automatically.
